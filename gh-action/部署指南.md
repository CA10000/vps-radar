# 部署到 GitHub + GitHub Pages（全部免费）

## 你会得到什么

- 每小时自动抓取（GitHub Actions 驱动）
- 自动 AI 审核真免费资源
- 公网可访问的网站，手机也能看
- 完全免费，不需要信用卡、不需要服务器

---

## 第一步：创建 GitHub 仓库

1. 打开 https://github.com/new
2. 填写：
   - Repository name：`vps-radar`
   - Visibility：选 **Public**
   - 不要勾选 Add a README file
3. 点 Create repository

---

## 第二步：上传代码

需要的文件结构：

```
.github/workflows/crawl.yml
src/run.js
src/ai-review-lite.js
docs/index.html
sources.js
fetcher.js
md-source.js
tg-source.js
package.json
```

注意：`.github` 是隐藏文件夹，网页拖拽可能失败。若失败，用 Add file -> Create new file，文件名填 `.github/workflows/crawl.yml` 再粘贴内容。

---

## 第三步：配置 API Key（关键）

1. 进入仓库 -> Settings -> 左侧 Secrets and variables -> Actions
2. 点 New repository secret
3. 填写：
   - Name：`DEEPSEEK_API_KEY`
   - Secret：粘贴你自己的 DeepSeek API Key（格式 `sk-xxxxxxxx`，从 https://platform.deepseek.com/api_keys 获取）
4. 点 Add secret

> 切勿把真实 Key 写进任何文件并提交到仓库。仓库是公开的，Key 一旦提交就会永久留在 git 历史里，必须立即去平台作废重发。

---

## 第四步：开启 Actions 写权限

1. 仓库 -> Settings -> Actions -> General
2. 拉到最下面 Workflow permissions
3. 选 Read and write permissions
4. 点 Save

这步不做，抓取完无法提交数据。

---

## 第五步：手动触发第一次抓取

1. 仓库顶部点 Actions
2. 左侧点 VPS Radar Crawl
3. 右侧点 Run workflow -> Run workflow
4. 等 2-3 分钟，看到绿色对勾就是成功
5. 回仓库，`docs/data.json` 应被创建

---

## 第六步：开启网页（GitHub Pages）

1. 仓库 -> Settings -> 左侧 Pages
2. Source 选 Deploy from a branch
3. Branch 选 `main`，目录选 `/docs`
4. 点 Save
5. 等 1-2 分钟，访问 `https://你的用户名.github.io/vps-radar/`

---

## 本地测试

```bash
cd gh-action
bun run src/run.js crawl    # 只抓取
bun run src/run.js          # 抓取 + AI 审核
```

## 安全提醒

- API Key 只能放在 GitHub Secrets，绝不能写进代码或文档
- 仓库设为 Public 时，任何人可查看代码（Secrets 加密不可见）
- 若 key 意外提交，立即去平台作废重发，光删文件无效（历史里仍有）

## 常见问题

Q：仓库必须公开吗？
A：不必。但 Public 的 Actions 无限免费，Private 只有 2000 分钟/月。

Q：数据会无限增长？
A：不会，代码限制最多 5000 条。

Q：能改抓取频率？
A：改 `.github/workflows/crawl.yml` 的 `cron`。`7 * * * *` = 每小时第 7 分钟。

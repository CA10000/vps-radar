---

## 第一步：创建 GitHub 仓库

1. 打开 https://github.com/new
2. 填写：
   - **Repository name**：`vps-radar`
   - **Visibility**：选 **Public**（免费 Actions 额度更多，私有也行但额度少）
   - **不要**勾选 "Add a README file"
3. 点 **Create repository**

---

## 第二步：上传代码

在仓库页面，点 **uploading an existing file** 链接，然后把下面这些文件和文件夹拖进去：

```
├── src/
│   ├── run.js
│   └── ai-review-lite.js
├── .github/
│   └── workflows/
│       └── crawl.yml
├── docs/
│   └── index.html
├── sources.js
├── fetcher.js
├── md-source.js
├── tg-source.js
└── package.json
```

⚠️ **重要**：`.github` 文件夹是隐藏的，拖拽时确保它被包含进去。如果拖不进去，用下面的方式：

在仓库页点 **Add file → Create new file**，文件名输入 `.github/workflows/crawl.yml`，把内容粘贴进去。

## 第三步：配置 API Key（关键）

1. 进入仓库 → **Settings** → 左侧 **Secrets and variables** → **Actions**
2. 点 **New repository secret**
3. 填写：
   - **Name**：`DEEPSEEK_API_KEY`
   - **Secret**：`sk-408e4a6d1fd34690a1eb7dfaed74c0fc`
4. 点 **Add secret**

---

## 第四步：开启 Actions 写权限

1. 仓库 → **Settings** → **Actions** → **General**
2. 拉到最下面 **Workflow permissions**
3. 选 **Read and write permissions**
4. 点 **Save**

⚠️ 这步不做的话，抓取完无法提交数据。

---

## 第五步：手动触发第一次抓取

1. 仓库顶部点 **Actions** 标签
2. 左侧点 **VPS 雷达自动抓取**
3. 右侧点 **Run workflow** → **Run workflow**
4. 等 2-3 分钟，看到 ✅ 绿色对勾就是成功
5. 回到仓库，应该能看到 `docs/data.json` 被创建了

---

## 第六步：开启网页（Cloudflare Pages）

1. 打开 https://dash.cloudflare.com/sign-up
   - 用邮箱注册即可，**不需要信用卡**
2. 登录后左侧点 **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
3. 授权 GitHub，选择你的 `vps-radar` 仓库
4. 构建设置：
   - **Framework preset**：`None`
   - **Build command**：留空
   - **Build output directory**：`docs`
5. 点 **Save and Deploy**

等 1 分钟，你会得到一个网址，类似：
```
https://vps-radar.pages.dev
```

**这个网址就是你的 24/7 免费站点。**

---

## 备选：用 GitHub Pages（更简单但稍慢）

如果不想注册 Cloudflare：

1. 仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 **Deploy from a branch**
3. **Branch** 选 `main`，**文件夹**选 `/docs`
4. 点 **Save**
5. 等 1 分钟，访问 `https://你的用户名.github.io/vps-radar/`

## 成本与限额

| 项目 | 免费额度 | 你的用量 |
|---|---|---|
| GitHub Actions | 2000 分钟/月（Public 仓库无限） | 每次约 3 分钟 × 720 次/月 = **2160 分钟** |
| DeepSeek API | 按量付费 | 每次 60 条约 7 万 tokens ≈ **¥0.05**，一天 24 次 ≈ **¥1.2/月** |
| Cloudflare Pages | 无限请求、无限带宽 | 无限制 |

⚠️ **注意**：Actions 2160 分钟略超 2000 分钟免费额度。两个办法：
1. 改成每 2 小时抓一次（`cron: "7 */2 * * *"`）
2. 仓库设为 **Public**（Public 仓库 Actions **完全免费无限**）

**推荐选 2**，把仓库设成 Public，一劳永逸。

## 常见问题

**Q：仓库必须公开吗？**
A：不必须。但 Public 仓库的 Actions 是无限免费的，Private 只有 2000 分钟。代码本身没有敏感信息（API key 存在 Secrets 里不会泄露）。

**Q：数据会无限增长吗？**
A：不会，代码里限制最多保留 5000 条。

**Q：能改抓取频率吗？**
A：改 `.github/workflows/crawl.yml` 里的 `cron` 表达式。`"7 * * * *"` = 每小时第 7 分钟。

**Q：AI 审核太慢怎么办？**
A：改 workflow 里的 `AI_MAX_PER_ROUND`，默认 60 条/次。
